## Core Type: LearningConcept

This is the central data type of the entire application. Every concept generated by the AI conforms to this interface. Every UI component, algorithm, and activity that touches a concept MUST consume the relevant fields — not hardcode alternatives.

```typescript
interface LearningConcept {
  // Identity
  id: string;
  name: string;
  stageId: string;
  order: number;
  icon?: string;

  // ========== TREE SYSTEM (REQUIRED) ==========
  tier: 'trunk' | 'branch' | 'leaf';      // LLM-declared, NOT computed
  parentName?: string;                      // Direct parent concept name
  trunkDomain?: string;                     // Top-level trunk this belongs to
  cognitiveLevel?: 'remember' | 'understand' | 'apply' | 'analyze' | 'evaluate' | 'create';
  lifecyclePhase: 'PREPARE' | 'MODEL' | 'DELIVER';
  dependencies: string[];                   // Concept IDs this depends on
  outdegree: number;                        // Count of concepts depending on THIS one
  commonPitfalls?: string[];                // Critical misconceptions
  connections?: Array<{
    target: string;
    type: 'requires' | 'enables' | 'is-part-of' | 'is-type-of' | 'causes' | 'constrains';
  }>;

  // ========== CORE CONTENT ==========
  hookSentence?: string;                    // Opening hook for learner attention
  whyYouNeed?: string;                      // Motivation for learning this concept
  howToUse?: string[];                      // Step-by-step application
  technicalDetails?: string;                // Deep technical explanation
  metaphor?: string;                        // Analogy for understanding
  workedExample?: WorkedExample;            // Problem + solution + steps
  realWorldExample?: string;                // Real-world application
  visualElement?: string;                   // Visual learning aid description
  actionButtonText?: string;                // CTA text

  // ========== METADATA ==========
  mnemonic?: MnemonicContext;               // Memory anchor system
  lifecycle?: ConceptLifecycle;             // 3-phase lifecycle with titles + steps
  shape?: ShapeContent;                     // SHAPE learning content
  prerequisites?: string[];                 // Name-based prerequisite list
  keyPoints?: string[];                     // Summary bullet points
}
```

## Field Usage Contract

Every field below MUST be consumed by the specified system. If you add a new consumer, update this table.

### Tree System Fields

| Field | Consumed By | How |
|-------|-----------|-----|
| `tier` | SensaSynopticView (badge), concept-selection.ts (difficulty scoring, tier balance), interleaving.ts (tier distribution), preview-ai.ts (difficulty level) | Tier badge color, ordering weight, difficulty calc |
| `parentName` | SensaSynopticView (breadcrumb), MicroLearningLoopController LearnPhase (breadcrumb hint), SessionScoutPreview + ContentLaunchpad (trunk inference fallback) | `trunkDomain › parentName › name` hierarchy; infers implicit trunks when no explicit trunk-tier concepts exist |
| `trunkDomain` | SensaSynopticView (breadcrumb), MicroLearningLoopController LearnPhase (breadcrumb hint), SessionScoutPreview + ContentLaunchpad (trunk inference primary) | Top-level domain label; used to synthesize virtual trunk entries for legacy content |
| `cognitiveLevel` | MicroLearningLoopController (Bloom's badge), concept-selection.ts (difficulty), preview-ai.ts (difficulty), PeerReviewActivity (reviewer expertise matching) | Visual badge + scoring factor |
| `lifecyclePhase` | concept-selection.ts (interleaving), interleaving.ts (phase scoring) | Alternates PREPARE/MODEL/DELIVER for variety |
| `dependencies` | concept-selection.ts (prerequisite gating) | ID-based prerequisite check |
| `outdegree` | concept-selection.ts (priority bonus), interleaving.ts (priority bonus) | Higher outdegree = learned earlier |
| `commonPitfalls` | MicroLearningLoopController LearnPhase (Critical Clarifications section), PeerReviewActivity (misconception generation), preview-ai.ts (question generation) | Surfaced as warnings + used for challenges |
| `connections` | concept-selection.ts (prerequisite gating via `requires`, enabler bonus via `enables`), interleaving.ts (prerequisite scoring, context bridge verb-based transitions) | Semantic ordering + transition narration |

### Connection Types (Verb System)
```typescript
type ConnectionVerb = 'requires' | 'enables' | 'is-part-of' | 'is-type-of' | 'causes' | 'constrains';
```

| Verb | Meaning | Algorithm Use |
|------|---------|--------------|
| `requires` | Must learn target first | Prerequisite gate — blocks concept until target is complete |
| `enables` | Learning this unlocks target | Priority bonus — enablers are taught earlier |
| `is-part-of` | This is a component of target | Context bridge: "Let's zoom in" |
| `is-type-of` | This is a variant of target | Context bridge: "A specific variant" |
| `causes` | This triggers target | Context bridge: "Let's follow the chain" |
| `constrains` | This limits target | Context bridge: "Understanding the boundaries" |

## Transformer Extended Types

## Bloom's Taxonomy Levels

Used in `cognitiveLevel` field. Ordered from simplest to most complex:

| Level | Description | Difficulty Weight |
|-------|------------|------------------|
| `remember` | Recall facts | +0 |
| `understand` | Explain ideas | +0 |
| `apply` | Use in new situations | +1 |
| `analyze` | Break down into parts | +1 |
| `evaluate` | Justify decisions | +2 |
| `create` | Produce new work | +2 |

## Subject Classification Types

Subjects are classified into 4 types during Phase 1 generation:

```typescript
type SubjectType = 'procedural' | 'conceptual' | 'cyclic' | 'perceptual';
```

| Type | Pattern | Examples |
|------|---------|---------|
| `procedural` | Sequential stages on object lifecycle | Azure admin, surgery, coding |
| `conceptual` | Core moves + application patterns | Law, philosophy, music theory |
| `cyclic` | Fundamental cycle + meta-awareness | Design thinking, research, jazz |
| `perceptual` | Perceptual ladder + practice structures | Diagnosis, chess, art critique |

Used by: `CreativeTransferActivity` (type-specific scenarios), `CognitiveStream` (classification-aware thoughts), generation prompts (type-aware content adaptation).

```typescript
// NEVER hardcode content that the AI generates
const sectionTitle = "The Architecture";     // WRONG — use lifecycle.phase1.title
const question = `What is ${name}?`;         // WRONG — use shape.patternRecognition.question first

// NEVER use old tier names
tier: 'root'           // FORBIDDEN
tier: 'foundation'     // FORBIDDEN
tier: 'keystone'       // FORBIDDEN
```
